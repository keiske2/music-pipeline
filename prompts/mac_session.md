# 맥 "이 컴퓨터" 세션용 작업 지시서 — 다음 곡 1개 만들기

맥 Claude 앱에서 **이 컴퓨터 + music-pipeline 폴더**로 새 세션을 열고,
지구본 버튼으로 오른쪽 브라우저를 연 뒤 아래 한 줄만 보내면 된다.

> prompts/mac_session.md 대로 다음 곡 1개 만들어줘

---

## Claude가 할 일 (순서대로)

1. **최신 내용 받기:** 이 폴더에서 `git pull` 한다.

2. **다음 곡 고르기**
   - `batch/` 폴더에서 가장 최근 달의 JSON(예: `batch/2026-11.json`)을 연다. 곡 순서는 파일에 적힌 순서다.
   - `uploaded.json`과 구글 드라이브 `Suno` 폴더(하위 날짜 폴더 포함)를 확인한다.
   - 아직 드라이브에 mp3가 없는 **첫 번째 곡**을 고른다.
   - 드라이브 파일 이름은 곡 제목에서 악센트·쉼표를 빼고 띄어쓰기를 `_`로 바꾼 것이다.
     예: `Corazón de Salsa` → `Corazon_de_Salsa`, `Uno, Dos, Chachachá` → `Uno_Dos_Chachacha`
   - 그 곡의 수노 입력값과 영상 프롬프트는 `lyrics/<key>.md`에 있다. `<key>`는 JSON의 `key` 값이다.

3. **수노에서 곡 만들기** (오른쪽 브라우저)
   - `suno.com/create` → 고급(Custom) 모드
   - Title, Style of Music, Exclude Styles, Lyrics를 `lyrics/<key>.md`에서 그대로 복사해 넣고 만들기
   - 완성되면 **첫 번째 버전**을 mp3로 받아 `<파일이름>.mp3`로 저장

4. **제미나이에서 영상 만들기** (오른쪽 브라우저)
   - `gemini.google.com` → 영상 만들기
   - `lyrics/<key>.md`의 "제미나이 영상 프롬프트"(영어)를 그대로 붙여넣기, 가로 16:9
   - 완성되면 `<파일이름>.mp4`로 저장

5. **드라이브에 올리기** (오른쪽 브라우저)
   - `drive.google.com` → `Suno` 폴더 안에 오늘 날짜 폴더(`YYYY-MM-DD`)를 만들고 mp3와 mp4를 올린다.

6. **끝나면 알려주기:** 만든 곡 제목과 드라이브에 올린 파일 이름 두 개를 알려준다.

## 멈춰야 할 때
- 수노·구글·제미나이 **로그인 화면이나 사람 확인(CAPTCHA)** 이 나오면 멈추고 사용자에게 직접 하라고 알린다.
- 수노 크레딧이 부족하거나 제미나이 영상 한도에 걸리면 멈추고 알린다.
- 같은 곡을 두 번 만들지 않는다. 드라이브에 이미 그 이름의 mp3가 있으면 다음 곡으로 넘어간다.
